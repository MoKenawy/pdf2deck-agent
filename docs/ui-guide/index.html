PDF2Deck Agent UI Guide
PDF2Deck Agent · how to use the UI

From chapter PDF to styled deck

Upload a chapter, pick a style, and the agent builds a PowerPoint deck from it. You approve twice: once on the outline, before anything is rendered, and once on the finished deck.

uv run pdf2deck
Then open the URL it prints, usually http://127.0.0.1:7860
  1. Upload PDF
  2. Set style
  3. Generate
  4. Approve outline
  5. Approve deck
  6. Download .pptx

The screen at a glance

Inputs live in the left column. Everything you review and approve appears in the right column. The style fields, the Generate button and the run log sit further down the left column.

    Inputs (left)

  1. Chapter PDF: the document to turn into slides.
  2. First page / Last page: optional. Leave both empty to use the whole PDF.
  3. Optional preferences file (JSON): a saved style. It replaces the style fields below it.
  4. Create a preferences file from a PPTX template: copies the look of an existing deck.

    5. Review (right)

  5. Status line: what the agent is doing, or what it needs from you.
  6. Outline: the proposed slides appear here for review.
  7. Approve / Reject outline: first checkpoint.
  8. PPTX output: the rendered deck, ready to download.
  9. Approve / Reject deck: second checkpoint.

Make a deck, step by step

STEP 1

Upload the chapter

Drop the PDF on Chapter PDF, or click it to browse. To use only part of the document, type page numbers into First page and Last page. Empty fields mean page 1 and the last page.

  1. The uploaded file shows its name and size. The × in the corner removes it.
  2. Page range. Whole numbers only; a first page after the last page is rejected before the run starts.
STEP 2

Choose a style and press Generate

Set Style name, Tone (formal, educational, executive or conversational), Density (sparse, balanced or dense) and Font. Then press Generate. If you already have a preferences file, upload it instead and skip these fields (see Reuse a deck's look).

  1. Reminder: while a preferences file is loaded, these four fields are ignored.
  2. The four style fields. The defaults shown (technical-minimal, educational, balanced, Aptos) work for most chapters.
  3. Generate starts a new run. Each press creates a new Run ID.
  4. Graph execution: a live log of each step. The one shown here is a finished run, from validate_input through validate_artifact.
STEP 3

Wait for the outline

Text and images come out of the PDF in seconds. Writing the outline with the language model is the slow part. For this 21-page chapter it took about 75 seconds, and longer chapters take several minutes. The page doesn't need any input while it works.

  1. The status line names the model in use and tells you this step is slow.
  2. Review buttons stay greyed out until there is something to review.
STEP 4

Review the outline Checkpoint 1

When the status says Outline ready for review, scroll the outline panel. It lists the deck title, the learning objectives, then every slide with its purpose, its key points, its layout type and any image it will use. Nothing has been rendered yet, so this is the cheapest place to catch problems.

  1. The status confirms the run is waiting for you.
  2. Deck title, subtitle and learning objectives.
  3. Each slide shows its layout type: title, concept, bullets, comparison or summary.
  4. Figures are taken from the PDF. img-p1-0 is the first image on page 1.
  5. Approve outline renders the deck.
  6. Reject outline stops the run. Change the inputs or style, then press Generate again.
STEP 5

Download and check the deck Checkpoint 2

Rendering takes a few seconds. The status reports how many slides were made, and the file appears under PPTX output. Download it, open it in PowerPoint, then come back and decide.

  1. Click the size link to download. The file is named after the run ID and is also saved in the project's outputs/ folder.
  2. Approve deck marks the run complete.
  3. Reject deck ends the run without approving it. Adjust the style and generate again.
STEP 6

Done

The status changes to Deck approved. The final file stays under PPTX output, and the outline stays on screen for reference.

Reuse a deck's look

A preferences file stores a whole style as JSON: colours, fonts, type sizes, slide size, tone and density. You can create one from any existing .pptx, then use it on any PDF. In the test run, the deck Gemini produced was turned into a preferences file this way.

STEP A

Extract preferences from a template

Open Create a preferences file from a PPTX template, drop a .pptx on PPTX template, and press Extract preferences.

  1. Click the section title to open or close it.
  2. The template deck. None of its content is copied into your slides.
  3. Extract preferences reads the theme colours and fonts, the common text sizes, the slide size, and how much text a typical slide holds (which sets the density).
  4. The result appears as JSON just below.
STEP B

Check the JSON and download the file

Read through the extracted values, starting with the colours. They come from the template's theme. A deck that colours its shapes directly, rather than through the theme, can return the theme's stock accents instead of the colours you see on its slides. That happened here.

  1. colors: here the theme's stock blue and red came back, not the greens used on the Gemini slides.
  2. Download or copy the JSON.
  3. Preferences file: the same JSON saved as <name>.preferences.json. Click the size to download it.
STEP C

Edit it if needed

Open the downloaded file in any text editor. In the test run, only the two accent colours were changed, to match the green of the source deck.

As extracted
main #4F81BD highlight #C0504D
After editing
main #4FBD8B highlight #348B64 
{
  "name": "introduction-to-biology",
  "tone": "educational",
  "density": "balanced",
  "colors": {
    "main": "#4fbd8b",
    "highlight": "#348b64",
    "text": "#000000",
    "background": "#FFFFFF"
  },
  "fonts": { "heading": "Calibri", "body": "Calibri" },
  "type_scale": { "title_pt": 27.0, "body_pt": 12.0 }
}
STEP D

Load it and generate

Upload the file to Optional preferences file (JSON), then press Generate and continue from step 3. The file stays loaded for later runs until you remove it.

  1. The loaded preferences file. Style name, Tone, Density and Font are now ignored.
  2. Remove it with × to go back to the style fields.

If the project's settings name a default preferences file, the style fields stay locked even with nothing uploaded, and the note above them names that file.

When something goes wrong

Messages appear as a pop-up or in the status line.

MessageWhat happenedWhat to do
Upload a PDF first.Generate was pressed with no chapter loaded.Add the PDF in step 1.
Invalid page range: …A page field holds something other than a page number, or the range is out of order.Fix the numbers, or clear both fields.
Stopped: Pages … are outside the PDF, …The page range goes past the end of the document.Use a last page within the PDF's page count, or leave it empty.
Stopped: Outline was rejected. …You pressed Reject outline.Change the inputs and press Generate for a fresh run.
Stopped: Deck was rejected.You pressed Reject deck.Adjust the style and generate again.
No outline is waiting for review.A review button was clicked after that checkpoint had passed.Check the status line to see where the run is.
Failed: …The model call or rendering raised an error.Read the terminal running uv run pdf2deck for details, then retry.
Upload a PPTX template first.Extract preferences was pressed with no template.Drop a .pptx on PPTX template.
